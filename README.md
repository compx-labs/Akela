# Akela

Multi-chain agent registry + ranking — held × volume × consistency Value (service history). Not a marketplace.

## Web app

```bash
npm install
npm run dev
```

Opens the agent terminal at [http://localhost:5173](http://localhost:5173). Desktop-first (`min-width: 1280px`).

API Worker (Hono): `npm run dev:api` → [http://localhost:8787/health](http://localhost:8787/health).

Views: Home, Boards, Agents, Formula, Register. Hero metric is Akela Value ($) — a model, not an offer.
